# Mobile-First Responsive UI Matrix & Testing

## 1. Target Viewport Matrix
* `360×640` (Small Mobile / Android entry devices)
* `390×844` (Standard Mobile / iPhone 12–15)
* `412×915` (Modern Android Flagship)
* `768×1024` (Tablet Portrait / iPad)
* `1024×1366` (Tablet Landscape / iPad Pro)
* `1440×900` (Standard Desktop & Laptop)
* `1920×1080` (Full HD Desktop)

## 2. Touch & Usability Standards
* Minimum $44\text{px}$ touch targets for all primary buttons, answer cards, and navigation toggles.
* Collapsible question palette drawer on viewports $< 768\text{px}$.
* Zero unwanted horizontal overflow on standard layout containers.
* Sticky top header for timer and quick action triggers.
